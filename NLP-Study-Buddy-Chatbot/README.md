# NLP Study Buddy Chatbot

## Project Overview

Enisteen is a rule-based NLP chatbot developed using Python and NLTK.

The chatbot answers questions related to Artificial Intelligence, Machine Learning, Deep Learning, NLP and Large Language Models.

---

## Problem Statement

Build an intelligent chatbot capable of understanding user queries and providing educational responses related to AI concepts.

---

## Technologies Used

- Python
- NLTK
- JSON

---

## Chatbot Architecture

User Query

↓

Text Preprocessing

↓

Intent Recognition

↓

Pattern Matching

↓

Response Selection

↓

Chatbot Reply

---

## Workflow

1. Receive User Input
2. Preprocess Text
3. Tokenize Input
4. Remove Stopwords
5. Identify Intent
6. Match Patterns
7. Generate Response
8. Store Chat History
