# IMDb Sentiment Analysis

## Project Overview

IMDb Sentiment Analysis is a Natural Language Processing (NLP) project that analyzes movie reviews and predicts their sentiment.

This project implements an NLP pipeline using NLTK and TextBlob for text preprocessing and sentiment analysis.

---

## Problem Statement

Analyze movie reviews and determine whether the sentiment expressed in the review is positive, negative, or neutral.

---

## Dataset

IMDb Movie Reviews Dataset

Columns:

- Review
- Sentiment

---

## Technologies Used

- Python
- NLTK
- TextBlob
- Pandas
- JSON

---

## NLP Pipeline

Input Review

↓

Stemming

↓

↓

POS Tagging

↓

Sentiment Analysis

↓

JSON Output

## Workflow

1. Load IMDb Dataset
2. Text Preprocessing
3. Tokenization
4. Stopword Removal
5. Stemming
6. Lemmatization
7. POS Tagging
8. Sentiment Analysis
9. Export Results to JSON
